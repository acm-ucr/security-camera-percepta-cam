## Project Description
### General Description
 * Percepta CAM is an object detection security camera that detects people, animals, and vehicles.

### Features
  * Real-time object detection for multiple categories (people, animals, vehicles).
  * Alerts when movement or specific objects are detected.
  * Confidence score

### Language / Technologies
 * Python – Core programming language for processing and detection.
 * Kaggle – Dataset sourcing and experimentation.
 * Roboflow – Createing object detection models.
 * YOLOv11 – Object detection architecture for high accuracy and speed.
